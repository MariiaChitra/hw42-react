# HW_42 Домашнее задание

# Task Manager

Создайте отдельный Vite + React JavaScript проект task-manager для управления задачами. Student CRM сохраните отдельно. Ориентир самостоятельной работы: 2–3 часа. Полное решение с дополнительными фильтрами приведено в приложении B.

Это будет небольшой менеджер задач.

## 1. Основные требования

Приложение должно позволять:

1. Отображать список задач.
2. Добавлять новую задачу.
3. Удалять задачу.
4. Отмечать задачу выполненной.
5. Возвращать задачу в статус невыполненной.
6. Показывать общее количество задач.
7. Показывать количество выполненных задач.
8. Очищать весь список.
9. Отображать сообщение при пустом списке.

На этом этапе можно добавлять задачи с заранее заданным текстом.

Ввод текста через форму будет изучаться на следующем уроке.

## 4. Требования к App

В `App` должны находиться:

- `useState` со списком задач.
- Функция добавления.
- Функция удаления.
- Функция изменения статуса.
- Функция очистки списка.
- Вычисление статистики.

## 5. Требования к TaskList

Компонент должен:

1. Получать задачи через props.
2. Использовать `map()`.
3. Использовать `key`.
4. Передавать обработчики в `TaskItem`.
5. Показывать сообщение при пустом списке.

## 6. Требования к TaskItem

Компонент должен отображать:

- Название задачи.
- Статус.
- Кнопку изменения статуса.
- Кнопку удаления.

## 7. Дополнительное задание

Добавьте кнопку:

```text

```

При нажатии должны удаляться только выполненные задачи.

Подсказка:

```javascript
filter()
```

## 8. Задание повышенной сложности ADV

Добавьте фильтрацию задач:

- Все.
- Выполненные.
- Невыполненные.

Используйте отдельное состояние:

```javascript
const [filter, setFilter] = useState("all");
```

И вычисляйте отображаемый список на основе выбранного фильтра. Фильтр не удаляет данные. Общая статистика считается по всем tasks, а не по видимому подмножеству. При tasks=[] показываем «Задач пока нет», при пустом результате фильтра — «Нет задач по выбранному фильтру». Добавленная невыполненная задача не будет видна под фильтром выполненных.
